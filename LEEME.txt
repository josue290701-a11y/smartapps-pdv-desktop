SMARTAPPS PDV — App de escritorio para Windows
================================================

Esta carpeta ya tiene todo listo (código, ícono, configuración). Solo falta
compilarla UNA VEZ en una computadora con Node.js e internet, para generar
el instalador .exe.

PASO 1 — Instalar Node.js (si no lo tienes)
--------------------------------------------
Descarga e instala la versión LTS desde: https://nodejs.org
(Solo se hace una vez en la computadora donde vayas a compilar.)

PASO 2 — Abrir esta carpeta en una terminal
--------------------------------------------
- Windows: entra a la carpeta, haz clic derecho dentro y elige
  "Abrir en Terminal" (o "Abrir ventana de PowerShell aquí").

  Si vas a subir esto a GitHub para que lo compile por ti (recomendado si
  compilas desde una tablet/celular), sube estos 6 archivos sueltos a la raíz
  del repositorio (sin carpetas): main.js, package.json, preload-print.js,
  icon.png, icon.ico, LEEME.txt — y además crea el archivo
  ".github/workflows/build.yml" (ese sí necesita ir en esa ruta con carpetas,
  créalo con "Add file > Create new file" escribiendo ese nombre completo).

PASO 3 — Instalar las dependencias
--------------------------------------------
Ejecuta:

    npm install

Esto descarga Electron y electron-builder (tarda unos minutos la primera vez).

PASO 4 — Generar el instalador
--------------------------------------------
Ejecuta:

    npm run dist

Al terminar, busca la carpeta "dist" dentro de este proyecto: ahí aparece
el instalador, por ejemplo:

    dist/SmartApps PDV Setup 1.0.0.exe

Ese archivo .exe es el que le compartes a cualquier PC con Windows: lo
ejecutan, se instala como cualquier programa, queda con su propio ícono
en el escritorio y en el menú inicio, y abre tu PDV en una ventana propia
(sin verse como un navegador).

PASO 5 — Probar antes de compilar (opcional)
--------------------------------------------
Si quieres probarlo sin generar el instalador todavía:

    npm start

Se abre la ventana de la app directo, cargando:
https://josue290701-a11y.github.io/Smartapps-PDV-App/


¿Cambiaste de dominio / URL del PDV?
--------------------------------------------
Abre el archivo "main.js" con cualquier editor de texto, busca la línea:

    const APP_URL = 'https://josue290701-a11y.github.io/Smartapps-PDV-App/';

y cambia la URL entre comillas por la nueva. Vuelve a correr "npm run dist".


IMPRESORA TÉRMICA (impresión directa, sin diálogo)
--------------------------------------------
Ya viene programada. Cuando tengas tu impresora térmica conectada e instalada
en Windows (aparece en "Configuración > Bluetooth y dispositivos > Impresoras
y escáneres"), solo tienes que decirle a la app cuál usar:

1. Abre "main.js" con un editor de texto.
2. Busca la línea:

       const PRINTER_NAME = '';

3. Si la dejas vacía (''), usará la impresora predeterminada de Windows
   (la que tengas marcada con la estrella/palomita en Windows).
   Si quieres apuntar a una en específico, copia su nombre EXACTO tal cual
   aparece en esa pantalla de Windows y ponlo entre las comillas, ejemplo:

       const PRINTER_NAME = 'XP-80C';

4. Vuelve a correr "npm run dist" para generar el instalador actualizado
   (o "npm start" para probarlo directo sin generar el instalador).

Con esto, cada vez que se imprima un ticket o un corte de caja, ya no sale
ningún diálogo de impresión — se manda directo a la impresora térmica.

Nota: esto está listo para el caso más común (impresora térmica USB que
Windows reconoce como impresora normal, con su driver instalado) — que es
justo el tipo de impresora recomendada (ej. Xprinter XP-80C). Si en tu caso
la impresora no aparece como impresora normal de Windows (por ejemplo, si
es de red/IP con su propio protocolo, o solo trae SDK propio), avísame el
modelo exacto y ajustamos el código para ese caso.


Notas
--------------------------------------------
- El instalador que se genera es de 64 bits (la gran mayoría de PCs actuales).
- No necesitas repetir el PASO 1 y 3 cada vez — solo si cambias de compu.
- Si Windows Defender/SmartScreen muestra una advertencia al instalar (por
  ser un .exe sin firma digital comprada), se resuelve dando clic en
  "Más información" → "Ejecutar de todas formas". Esto es normal en apps
  que no pagan un certificado de firma de código; no significa que esté
  dañado.
